작업 입력

호기별 엑셀 파일을 열어주세요

같은 양식의 파일을 열면 항목이 그대로 나타나고, 입력한 내용은 그 파일에 반영해 저장할 수 있어요.

    구역을 고르고 칸마다 값을 입력하세요. ± 버튼은 음수 부호(-)를 넣고 빼요. 키보드의 다음(Enter) 키로 다음 칸으로 넘어가요. 표 모양으로 보려면 "표로 보기"를 켜세요. 사진 영역은 엑셀에서 직접 붙여넣어야 해요.

    사용 방법

    내 이름

    완료 체크할 때 작업자 칸에 자동으로 들어갑니다.

    엑셀 저장

    입력한 내용을 연 파일에 반영해 새 엑셀로 저장합니다. 서식과 다른 시트는 그대로 유지돼요.

    공수 자동 입력

    끄면 지금까지 들어간 내용은 그대로 두고 더 이상 자동으로 바꾸지 않아요.

    공유 저장

    엑셀을 저장할 때 체크리스트와 특이사항을 공유 서버(구글 드라이브)에 호기별로 함께 올려, 다른 사람도 볼 수 있게 해요. 서버 주소가 이미 들어 있어서 따로 설정할 필요가 없어요.

    엑셀을 열면 다른 사람이 이미 완료한 항목과 특이사항을 공유 서버에서 받아 와요. 내가 직접 바꾼 칸은 건드리지 않아요. 끄면 장비 현황의 「공유 내용 가져오기」로 직접 받을 수 있어요.

    자동 복구

    열어 둔 엑셀과 입력 내용을 이 기기에만 임시 저장해 두었다가, 앱이 다시 열리면 그대로 복구해요. 7일이 지나면 지워져요. 다른 사람과 공유하는 기기라면 끄거나 아래 버튼으로 지우세요.

    파일

    다른 앱에 다녀와도 작업이 복구되지만, 작업을 마치면 꼭 엑셀로 저장하세요.
