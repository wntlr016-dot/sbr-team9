작업 입력

호기별 엑셀 파일을 열어주세요

같은 양식의 파일을 열면 항목이 그대로 나타나고, 입력한 내용은 그 파일에 반영해 저장할 수 있어요.

    구역을 고르고 칸마다 값을 입력하세요. ± 버튼은 음수 부호(-)를 넣고 빼요. 키보드의 다음(Enter) 키로 다음 칸으로 넘어가요. 표 모양으로 보려면 "표로 보기"를 켜세요. 사진 영역은 엑셀에서 직접 붙여넣어야 해요.

    사용 방법

    내 이름

    완료 체크할 때 작업자 칸에 자동으로 들어갑니다.

    엑셀 저장

    입력한 내용을 연 파일에 반영해 새 엑셀로 저장합니다. 서식과 다른 시트는 그대로 유지돼요.

    공수 자동 입력

    끄면 지금까지 들어간 내용은 그대로 두고 더 이상 자동으로 바꾸지 않아요.

    파일

    입력한 내용은 앱을 닫으면 사라져요. 작업을 마치거나 앱을 닫기 전에 꼭 엑셀로 저장하세요.

    앱 버전 v42

    점검
    일일보고

    작업자·완료일은 체크리스트에서, 작업일수는 공수 시트에서 가져와요. 날짜나 설정을 바꾸면 내용이 다시 만들어지고, 직접 고친 부분은 그때 사라져요.
